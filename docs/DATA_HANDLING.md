# 数据与隐私说明

仓库只保存程序及运行所需的结构和通用配置。实际门店数据由使用者在本机产生和管理。

## 上传范围

可提交：前后端源码、依赖清单及锁文件、Prisma 结构、通用配置初始化、无凭据的 `.env.example`、文档、合成测试夹具。

不提交：

- SQLite 业务数据库及 WAL、SHM、journal 等边车文件。
- `uploads/` 中的实物照片、缩略图和临时影像。
- 客户及交易方导出、订单、库存及财务数据导出。
- `backups/`、恢复暂存目录、恢复日志及维护锁。
- `.env`、密钥、令牌、个人机器路径和本地凭据。
- 运行日志、助手工作记录、测试产物和包含真实业务数据的截图。
- `node_modules/` 和构建目录。

这些路径由 `.gitignore` 排除。不要使用 `git add -f` 强制加入。新建导出格式或数据目录时，应同步补充排除规则并检查暂存文件。

## 首次初始化

`server/prisma/seed.js` 仅写入默认店名、空电话、默认位置及运行参数，不创建客户、价格、库存、交易或照片。

`scripts/tests/` 中的交易名称、价格、图片和数据结构用于独立合成测试，不来源于门店实际单据。测试数据库仅在本机 `.test-work/` 生成。

## 备份与协作

源码仓库不替代数据库与影像的联合备份。分享故障信息时，优先提供步骤、版本、错误类型和经核对的无业务数据示例，避免直接发送 `.env`、数据库、照片或完整备份。
